# probe：kprobe / kretprobe / ksyscall / uprobe / usdt

每个表按"挂载类型、类别（子系统）、事件名、描述、例子、头文件"整理。总览见 [bpf_known.md](bpf_known.md)。数据来自测试节点（内核 4.18.0-193.el8.jd_001.x86_64）和仓库内 libbpf，只代表该内核。

## kprobe / kretprobe / ksyscall

- 来源：测试节点（内核 4.18.0-193.el8.jd_001.x86_64）的 `/sys/kernel/tracing/available_filter_functions`，只读获取，共 46573 个可挂载函数。
- 写法：`SEC("kprobe/<函数名>")`（入口）、`SEC("kretprobe/<函数名>")`（返回）。`ksyscall/<系统调用名>` 由 libbpf 自动找到对应的内核函数（x86_64 上为 `__x64_sys_<名称>`）。
- 上下文：`struct pt_regs *ctx`，用 `PT_REGS_PARM1(ctx)` 等宏读参数，`PT_REGS_RC(ctx)` 读返回值；`ksyscall` 可用 `BPF_KSYSCALL` 宏直接声明参数。
- 限制：函数名随内核版本变化，被内联或标记为 notrace 的函数不在列表中；模块函数只有在模块加载后才出现。

## uprobe / uretprobe / usdt

- 可挂载的符号取决于具体的二进制或共享库，没有全局列表。查询：`nm -D <库文件>` 或 `objdump -T <库文件>`；USDT 探针用 `readelf -n <二进制>` 查看 `stapsdt` 段。
- 路径必须是绝对路径。

| 挂载类型 | 类别（子系统） | 事件名 | 描述 | 例子 | 头文件 |
|---|---|---|---|---|---|
| `uprobe` | 用户态二进制或共享库 | `<路径>:<符号>` | 用户态函数入口 | `SEC("uprobe//usr/lib64/libc.so.6:malloc")` | `<bpf/bpf_tracing.h>` |
| `uretprobe` | 用户态二进制或共享库 | `<路径>:<符号>` | 用户态函数返回，可读返回值 | `SEC("uretprobe//usr/lib64/libc.so.6:malloc")` | `<bpf/bpf_tracing.h>` |
| `usdt` | USDT 提供者 | `<提供者>:<探针>` | 用户态静态探针，需二进制编译进探针；路径可在 SEC 中写或由用户态 attach 时指定 | `SEC("usdt/libc:setjmp")` | `<bpf/usdt.bpf.h>` |
